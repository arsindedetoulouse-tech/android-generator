# Proposal

## Why

Проект `android-skeleton` уже пригоден к использованию (145 тестов проходят, версия 0.3.0 зафиксирована), но он не опубликован: у публичного репозитория нет лицензии, описания, CI, тега релиза, а пакет недоступен на PyPI. Без этого первый пользователь не может ни установить инструмент, ни доверять ему — при этом весь релизный цикл можно закрыть один раз и затем повторять на каждой версии.

## What Changes

- Добавляется MIT-лицензия в корень репозитория и раздел о лицензировании в README.
- Английская версия README становится основной (`README.md`), русская переезжает в `README.ru.md` со взаимными ссылками; в обоих появляется явная строка о расхождении имён.
- Добавляется CI: тесты на Python 3.11–3.13 и проверка собираемых артефактов (`build` + `twine check`).
- Публикация пакета на PyPI переводится на Trusted Publishing: отдельный workflow, запускаемый тегом релиза, без долгоживущего API-токена.
- Репозиторий публикуется как `android-skeleton 0.3.0`: тег `v0.3.0` и GitHub Release, чтобы проверка версий CLI находила релиз вместо предупреждения.
- Метаданные GitHub (описание, топики) приводятся в соответствие содержимому проекта.
- Изменений в поведении генератора нет: требования `android-project-generator` не затрагиваются.

## Capabilities

### New Capabilities

- `package-distribution`: как распространяется сам CLI — что попадает в публикуемые артефакты, какие проверки обязаны проходить до релиза и как пользователь получает пакет.

### Modified Capabilities

- Нет: поведение генератора не меняется, требования `android-project-generator` остаются в силе без правок.

## Impact

- Новые файлы: `LICENSE`, `.github/workflows/ci.yml`, `.github/workflows/publish.yml`, `README.ru.md`.
- Изменяемые файлы: `README.md` (язык, раздел о лицензии, ссылка на русскую версию).
- Внешние системы: PyPI Trusted Publishing (требует одноразовой регистрации publisher на pypi.org), GitHub Releases и теги.
- Вне области: переименование репозитория, перевод внутренней документации проекта, публикация пакета под другим именем.
